Merge Tactics, an auto-battler framework for Unreal

Unreal Engine 5.8 · C++ · replication · GAS · Fab

13,800 lines of C++ that I wrote alone and sell on Fab. The server simulates each round and sends clients an event log to replay, so no client can fake a result.

  • Four Blueprint interfaces, so buyers extend it without C++
  • A GAS bridge that maps stats onto an existing AttributeSet
  • Hex and square grids from one board asset
Read the source on GitHub

Merge Tactics match flow, server to client

  1. Prep. Players place units on the board.
  2. Lock. The server snapshots both boards.
  3. Simulate. The server runs combat: targeting, abilities, traits.
  4. Replicate. It sends a compact, ordered event log.
  5. Replay. Clients play the log back as animation and effects.

Ktrl Smash fix: WebGL ping drift

Problem: ping climbed over a session, from 20 to 60 ms on Windows and from 40 to 100 ms on WebGL.

Cause: per-frame work piled up on WebGL's single main thread, worsened by frequent network updates and redundant replicated state.

Fix: I audited coroutines, cut the update rate and payload size, and removed unneeded replicated variables. Ping now stays flat.
