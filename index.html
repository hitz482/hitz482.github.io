Details×
Overview
Server-authoritative auto-battler framework for Unreal Engine 5.8. Built alone (~13,800 lines of C++), published as a paid, source-available product, and designed so buyers ship a full game without writing C++.
Netcode
The server locks board snapshots, simulates, and replicates a compact event log that clients replay. Clients never compute outcomes, so match results can't be cheated.
Modules
HMT_Core 6.2k lines, HMT_CoreEditor 1.3k and HMT_GASBridge 0.3k, plus a 6.0k sample game. Drops into a project by copying three folders.
Extension
Four Blueprint interfaces (stat provider, targeting, trait effect, ability executor) cover every extension point. A GAS bridge maps stats onto an existing AttributeSet per unit.
Editor tools
Click-to-paint board editor, unit editor with live 3D preview and montage playback, and a save-time validator across seven data-asset types.
Round loop
Prep, combat and results phases, recency-weighted pairing, ghost boards for odd lobbies, PvE rounds, spectating and late-join. Hex and square grids from one asset.

Ktrl Smash

Multiplayer arena brawler · Unity · Photon Fusion · AWS · Steam + WebGL · Dec 2025

Free-to-play online PvP brawler, rated Mostly Positive on Steam. I built the multiplayer layer on Photon Fusion and worked with devops to deploy dedicated servers on AWS.

Debugging story Ping climbed over each session: 20→60 ms on Windows, 40→100 ms on WebGL. The cause was per-frame work piling up on WebGL's single main thread, made worse by chatty network updates and redundant replicated state. I audited coroutines, cut update rate and payload size, and removed unneeded replicated variables. Ping now stays flat for the whole session.
Steam page

The Cursed Hour

4-player online co-op horror · Unreal Engine 5 · EOS + Steam SDK · Nov 2024

Co-op survival horror in a haunted mansion. I pitched the original concept and owned the core multiplayer systems through to launch: the ghost NPC, the lobby and session layer, and text and voice chat.

Engineering note I integrated Epic Online Services and the Steam SDK side by side for a planned cross-platform rollout, keeping the session layer backend-agnostic. Around 18–23k estimated players and 129 reviews.
