Featured · Solo project · On Fab

HITZ: Merge Tactics

A server-authoritative auto-battler framework for Unreal Engine 5.8. Built alone, published as a paid product, and designed so buyers can ship a full game without writing C++.

  • UE 5.8
  • C++
  • Replication
  • GAS
  • Editor modules
  • Data assets
  • Server-authoritative combat. The server locks board snapshots, simulates, and replicates a compact event log that clients replay. Clients never compute outcomes, so match results can't be cheated.
  • Four modules, cleanly split. HMT_Core (6.2k lines), HMT_CoreEditor (1.3k) and HMT_GASBridge (0.3k), plus a separate sample game (6.0k). Drop the framework into a project by copying three folders.
  • Blueprint-first extension. Four interfaces (stat provider, targeting, trait effect, ability executor) cover every extension point without C++.
  • GAS bridge. Maps the stat interface onto an existing AttributeSet, per unit, with zero changes elsewhere.
  • Editor tooling. Click-to-paint board editor, unit asset editor with live 3D preview and montage playback, and a save-time validator.
  • Full round loop. Prep, combat and results phases, recency-weighted pairing, ghost boards for odd lobbies, PvE rounds, spectating and late-join. Hex and square grids from one asset.

Multiplayer games on Steam

Ktrl Smash

Unity · Photon Fusion · AWS dedicated servers · Steam + WebGL · Dec 2025

Free-to-play online PvP arena brawler, rated Mostly Positive on Steam. I built the multiplayer layer on Photon Fusion and worked with devops to deploy dedicated servers on AWS.

Debugging story Ping climbed over each session: 20→60 ms on Windows, 40→100 ms on WebGL. The cause was per-frame work piling up on WebGL's single main thread, made worse by chatty network updates and redundant replicated state. I audited coroutines, cut update rate and payload size, and removed unneeded replicated variables. Ping now stays flat for the whole session.
Steam page

The Cursed Hour

Unreal Engine 5 · 4-player online co-op · EOS + Steam SDK · Nov 2024

Co-op survival horror in a haunted mansion. I pitched the original concept and owned the core multiplayer systems through to launch: the ghost NPC, the lobby and session layer, and text and voice chat.

I integrated Epic Online Services and the Steam SDK side by side for a planned cross-platform rollout, keeping the session layer backend-agnostic. Around 18–23k estimated players and 129 reviews.
