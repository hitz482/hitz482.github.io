# hitz482.github.io

Portfolio site for Aman Khandelwal. Plain HTML, one stylesheet (`style.css`) and one small script (`main.js`). No framework and no build step is needed to host it.

## Layout

- `index.html`: homepage (hero, selected work, engineering summary, expertise, experience, independent projects, about, contact)
- `engineering.html`: four engineering case studies
- `projects/*.html`: one detail page per project
- `assets/img/`: screenshots and key art; `assets/*.pdf`: resumes
- `share.jpg`: Open Graph image

## Publish on GitHub Pages

Settings, Pages, Source: "Deploy from a branch", branch `main`, folder `/ (root)`. The site is served at https://hitz482.github.io. The docs sites at `/HitzMergeTactics/`, `/HitzGeoMap/` and `/HitzGasToolkit/` are separate repositories and keep working.
